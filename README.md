# mobile_lol · 星耀峡谷(网页 MOBA)

致敬《英雄联盟手游》的同人网页 Demo:单个 HTML 文件、零依赖、离线可玩。
2D 俯视角 Canvas 渲染,三路地图 + 野区,纯手游摇杆操作(电脑上用鼠标拖摇杆也可以)。

## 在线游玩

**https://junchen19.github.io/mobile_lol/**

## 怎么开玩

用手机或电脑浏览器直接打开 `index.html` 即可(建议横屏)。
也可以在局域网起个服务,手机扫码访问:

```bash
cd lol-web
python -m http.server 8000
# 手机访问 http://<电脑IP>:8000
```

## 操作

| 操作 | 说明 |
|---|---|
| 左半屏拖动 | 浮动虚拟摇杆,控制移动 |
| ⚔ 普攻按钮 | 优先攻击射程内敌方英雄(锁定 3 秒);站着不动会自动普攻 |
| Q / W / E | 小技能,自动瞄准最近的敌人(敌人优先),摇杆方向决定突进/弹道方向 |
| R | 大招,5 级解锁 |
| ⛶ 全屏 | 安卓/电脑直接全屏并锁横屏;iPhone 请「分享 → 添加到主屏幕」后从图标打开 |
| ⌂ 回城 | 引导 3.4 秒回泉水,移动或受击会打断 |
| 商店 | 随时购买,金币够时按钮有角标提示 |

## 玩法内容

- 三路兵线(每波 5 只,每三波加一台攻城车)、每路外塔/内塔、门牙塔与水晶,摧毁敌方水晶获胜
- 五位经典英雄(机制还原):盖伦、艾希、拉克丝、易大师、亚索,各 4 技能 + 被动
  (Q 致命打击 / W 勇气 / E 审判 / R 德玛西亚正义;寒冰普攻减速+全图水晶箭;拉克丝光之束缚禁锢+终极闪光巨束;剑圣阿尔法突袭不可选取+冥想;亚索风之障壁可挡弹道+第三段 Q 击飞接大)
- 队友 2 人 + 敌方 3 人均为 AI:对线、放技能连招、残血撤退回城、泉水回复、自动买装备
- 野区带墙体碰撞:石甲虫(金钱经验)、峡谷守望者(全队推塔增益)、星耀巨龙(全队伤害加成,可叠加)
- 击杀赏金、连杀播报、一血、助攻、补刀、自然金币与经验(快节奏,约 10~15 分钟一局)
- 装备商店 9 件装备(AD/AP/防御/鞋子,最多 6 件)
- 结算面板:双方 KDA / 补刀 / 金币 / 输出统计

## 想调数值?

全部在 `index.html` 的 `PART 2` 配置区:`CHAMPS`(英雄)、`ITEMS`(装备)、`MONSTER_DEF`(野怪)、`WAVE_INT`(出兵间隔)、`TURRET_DEFS`(防御塔)。
